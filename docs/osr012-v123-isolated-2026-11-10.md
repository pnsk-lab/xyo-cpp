# OSR-012 — Dynamic inner TIMES native continuation

2026-11-10. Base: OSR-011 local commit `250b699` (derived from v1.2.3
through OSR-010), independent branch `work/osr012-v123`.
No OSR-013+ runtime ABI or other shared experimental source changes included.

## Scope

Dynamic inner `repeat(TIMES)` is enabled only when all four flags are set:

- `XYO_JIT_OSR_NESTED_INFLIGHT_DEOPT=1`
- `XYO_JIT_OSR_NESTED_SOURCE_PROOF=1`
- `XYO_JIT_OSR_NESTED_INNER_YIELD_DEOPT=1`
- `XYO_JIT_OSR_NESTED_INNER_DYNAMIC=1`

The compiler accepts only an acyclic pure TIMES reporter AST with
`data_variable`, finite numeric literals, `operator_add`, and
`operator_subtract`; a real variable reference is mandatory. Depth <=4,
max 12 nodes; multiply/unknown/extension reporters are rejected.
The inner body may modify TIMES with `data_setvariableto` only when
the dynamic opt-in is selected, and the existing pure VALUE source
proof also passes.

The native private countdown is established on entry; later changes to
the TIMES variable do not reset it, even when block counting requires
source reporter re-evaluation. Opaque batching, GPU and par-for are
disabled for this protected native inner loop; real Fiber handoffs are
preserved.

A half-integer Scratch TIMES is rounded toward positive infinity.
The native LLVM f64 counter has not decremented at the post-body yield,
so the exact interpreter source counter is
`floor(innerAfterBody + 0.5)`. A valid final yield may carry -0.5,
which must become source zero. The original mutable reporter is never
re-evaluated during Interpreter restoration.

## Tests

Four new CTests: default/fast and active native TIMES mutation/
active-fast. The default fixture exercises variable, +1, -1, +0.5,
source edit and rejection of multiplication. The active fixture resets
TIMES to 17 at each outer iteration and changes it to 7 *inside*
the running native inner repeat. Both verify exact Interpreter state
and real LLVM Fiber yield/resume.

Source: `src/jit/backend_llvm.cpp`, `src/jit/rt.cpp`,
`src/jit/codegen.cpp`, `tests/CMakeLists.txt` and two fixture files.

Logs: `osr012-targeted.log`, `osr012-full-ctest.log`.
Uncommitted until full verification. No remote push or release.
