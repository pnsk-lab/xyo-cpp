## Strict opt-in and source proof

Four lexical counted repeats (selected outer, middle, deep, leaf) are
accepted only when all of the following flags equal 1:

- `XYO_JIT_OSR_NESTED_SOURCE_PROOF`
- `XYO_JIT_OSR_NESTED_INFLIGHT_DEOPT`
- `XYO_JIT_OSR_NESTED_INNER_YIELD_DEOPT`
- `XYO_JIT_OSR_NESTED_INNER_DYNAMIC`
- `XYO_JIT_OSR_NESTED_TRIPLE_YIELD`
- `XYO_JIT_OSR_NESTED_QUAD_YIELD`

The last flag defaults to OFF. Source verifier requires exactly three
nested `control_repeat` nodes under the selected outer repeat; it
freezes all three nested source IDs and rejects any fifth loop,
branching, unsupported or cyclic source path. Pure variable, finite
numeric literal and add/sub TIMES reporters retain OSR-012 proof
limits; the loop bodies retain its side-effect-free VALUE whitelist.
The private native loop counters remain authoritative when TIMES
variable values change during execution.

## Phase-4 suspension and source restoration

- Append `JitCtx::nestedOsrDeoptFourthRemaining` (double) and
  `CompiledScript::nestedOsrFourthLoopId` (string), without moving
  existing field offsets.
- At a genuine deepest native LLVM Fiber yield (after the completed
  leaf body), pass the current selected-outer, middle, deep and leaf
  private counters as post-body source-latch values to
  `xyo_rt_nested_osr_quad_yield_checkpoint`.
- Invalidate previous checkpoint readiness and phase first; validate
  finite, bounded values, normalize each fractional nested counter
  with `floor(v + 0.5)` and publish phase 4 only if every count is
  valid. This is **not** a generic SSA/effect-PC deoptimizer.
- On real editor source change, verify source digest/revision as
  before and prove all three frozen parent-to-child SUBSTACK paths
  still exist in the edited source. On success, discard the
  suspended LLVM Fiber, keep the real GC-rooted Interpreter
  caller/outer frames and restore middle/deep/leaf counted
  StackFrames in lexical order with the exact saved counter.
  Unprovable source or counter state fails closed.
- Existing phase 1/2/3 paths and their default-off flags are
  preserved; the new quad capture takes priority only in 4-level
  opt-in mode.
