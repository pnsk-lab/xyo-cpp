# OSR-013: 三階層 counted repeat のネイティブ中断から復帰

2026-11-10。公開 v1.2.3 を起点に OSR-010 → OSR-011 → OSR-012 と
独立コミットで統合したブランチ `work/osr013-v123` の追加機能。
親コミットは `fe282d2`。共有の大量の未コミット実験ソースは持ち込まない。

## 機能範囲

選択済み外側 `repeat` → 中間 `repeat` → 最深部 `repeat`
という **ちょうど三階層**のみを扱う。

実験フラグ `XYO_JIT_OSR_NESTED_TRIPLE_YIELD=1` は、
`XYO_JIT_OSR_NESTED_INNER_DYNAMIC=1`、
`XYO_JIT_OSR_NESTED_INNER_YIELD_DEOPT=1`、
`XYO_JIT_OSR_NESTED_INFLIGHT_DEOPT=1`、
`XYO_JIT_OSR_NESTED_SOURCE_PROOF=1` との組み合わせでのみ有効。
初期値は無効。

ソース検証は、合計2つの内側 `control_repeat` を順に要求。
深さ・循環・複数兄弟・未知の文や回数式は拒否する。
内側 `TIMES` は OSR-012 の純粋な変数・数値・加減算のASTのみ。
先頭・中間・最深部のソースIDをコンパイル時に固定する。

## 復帰ABI

- `JitCtx::nestedOsrDeoptDeepRemaining` を末尾に追加。
- `CompiledScript::nestedOsrDeepInnerLoopId` を追加。
- LLVMの最深部の実際のFiber yieldで3つのLLVM private counterを
  `xyo_rt_nested_osr_triple_yield_checkpoint` に渡す。
- 中間と最深部の小数カウンターを Scratch の半端を切り上げる
  `floor(v + 0.5)` で source latch へ正規化し、phase=3として記録。
  古い phase=1/2 checkpoint は無効化する。
- ソース編集後、元のFiberを破棄し、既存のGC-root済み呼出しフレーム
  と外側の `repeat` フレームを維持。元のソースID・構造・各残回数を
  再検証して、中間→最深部の順に2つのInterpreterフレームを復元。
- 安全に復元できない場合はfail-closedでスレッドを終了。
  任意SSA値や汎用的なeffect-PC再構成は行わない。
