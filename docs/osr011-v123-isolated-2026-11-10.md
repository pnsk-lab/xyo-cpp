## Source proof

Only `XYO_JIT_OSR_NESTED_INNER_YIELD_DEOPT=1`, jointly with
`XYO_JIT_OSR_NESTED_INFLIGHT_DEOPT=1` and
`XYO_JIT_OSR_NESTED_SOURCE_PROOF=1`, enables this mode.

A single directly nested repeat has a statically proved finite integer literal
trip count from 1 through 8192; its inner body is at most four numeric
increment statements. The existing OSR-010 whitelist validates VALUE
reporters as bounded, side-effect-free and acyclic. Unknown, extension,
dynamic, and otherwise unsupported shapes are refused.

OSR-010's `XYO_JIT_OSR_NESTED_INNER_BOUNDED` retains its existing behavior;
when both are requested, the true inner yield takes precedence, rather than
silently using an atomic lowering.

## Native ABI and semantics

- `JitCtx`: append `nestedOsrDeoptPhase` (0 invalid / 1 outer / 2 inner)
  and `nestedOsrDeoptInnerRemaining` without moving existing offsets.
- `CompiledScript`: freeze the source inner loop ID and its eligibility
  guard at compilation time, not after an editor change.
- LLVM: emit a phase-2 checkpoint with the two independent live native
  loop counters only at an actual inner body Fiber yield. Suppress opaque
  repeat batching, GPU, and par-for lowering on the protected loop but
  **keep the real scheduler yield**.
- RT: validate a finite integer pair after the just-completed source
  body, drop any previous valid checkpoint if current values are invalid,
  and record the phase under the yielding Fiber's exclusive ownership.
- Sequencer: on source revision mismatch, verify the frozen inner ID
  remains attached to the selected outer repeat, validate both counters
  and the original frame's provenance. Dispose of the suspended native
  Fiber *before* execution transfer, preserve the original interpreter
  caller frames and their GC roots, and add a synthetic inner repeat
  StackFrame with its exact saved counter. Invalid provenance fails closed.

This is **not** general arbitrary LLVM SSA/effect-PC deoptimization.
