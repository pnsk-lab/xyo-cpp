# 手続きの遅延JIT（2026-11-03）

## 実装
`XYO_JIT_LAZY_PROCEDURES=1`でLLVM ORC `LLLazyJIT`を有効化する。16関数以上のスクリプトのみ`addLazyIRModule`を使用し、通常の`CompiledScript::procedures`への全手続き一括lookupを省く。16関数未満では通常の`addIRModule`を使用する。既定では従来のLLJITを使用し、AOTのコードは変更しない。LLVMのコンパイルスレッドを2つ使用することで、複数スクリプトの同時遅延呼出しによる非並列TargetMachineのSIGSEGVを回避した。

## 実測
最大のparityスクリプトは166関数・約17万LLVM IR命令。初回compile処理は遅延JIT約1.42〜1.45秒（従来約3秒）だが、実行時に発生するコンパイルは含まれない。全体終了までの実時間は、従来6714〜6733msに対し遅延JIT8040〜8065ms（いずれも2123/2123）。

独立のgate制御テスト（`python3 tests/bench/algos/jit_lazy_procedure_fixture.py 60 18`）では、60個の手続きのほとんどが未使用の場合に457ms→252ms、全手続きを実行する場合に450ms→1013ms。両方式の出力は一致。各1回の観測値。

47ワークロードの実行性能（遅延/通常）は幾何平均0.989倍。非スケジューラ項目のチェックサムは全件一致。

## 留保
並列機械語生成を修正した後の連続3回のparityは2123/2123だったが、それ以前の反復実行では乱数規則テストが断続的に1件失敗していた。完全な正当性は未証明。既定化しない。

LLVM SplitModuleの単純な4・8・16分割は初回コンパイルを改善せず、分割後の遅延O3最適化も遅かったため関連実験コードは撤回した。次は実測の手続き呼出し頻度を使ったhot/cold分離と安全な再コンパイルが課題。


## 追加実験：最適化も関数単位に遅延する

`XYO_JIT_LAZY_PROCEDURES=1 XYO_JIT_LAZY_IR_OPT=1`の組み合わせで、16関数以上のスクリプトのO3最適化をコンパイル開始時に実行せず、ORCの`IRTransformLayer`で関数の実体化時に実行する。LLVMの`ModuleFlag`で遅延対象を明示し、16関数未満の通常モジュールでは最適化を二重実行しない。最適化レベルは従来の`XYO_JIT_OPT_LEVEL`と共通の選択関数を使う。

**既定では無効**。通常のJITのO3先行最適化はそのまま。

- 大型パリティスクリプト（166関数・約17万命令）の初回`compile()`は約351ms（機械語生成のみ遅延した場合約1.42秒、通常約3秒）。全件2123/2123に一致。
- ただしパリティSB3の実行完了までの壁時計時間は通常JITが6741〜6860msに対し遅延O3は8200〜8395msと悪化。この数値はコンパイル費用を「初回呼出し」へ先送りしたことによるもの。
- 独立の60手続きテストを、オーバーフローしない`value += (value % 7) + 1`という動的数値計算へ変更し、出力の区別を可能にした。`gate=0`（大半の手続き未実行）では通常1172ms→遅延213ms、出力1。`gate=1`（全手続き実行）では通常1149ms→遅延1500ms、出力2521。各1回測定。
- 乱数テストの断続的失敗は未解明。ただし`XYO_SEED=1`固定、並列実行あり、通常JITと遅延JITを交互に4回ずつ走らせた全8回では、2123/2123が連続成功した。シード固定・並列無効でも4回とも成功した。再発しないことの証明ではない。

実験コードの位置は`src/jit/jit.cpp`、入力生成は`tests/bench/algos/jit_lazy_procedure_fixture.py`。既定化はしない。

追加検証（同一47ワークロード各1回、通常JITと遅延O3比較）では、遅延O3/通常のops/msの幾何平均は**1.008倍**。非スケジューラ項目でチェックサム不一致は0件。ops/msはスクリプト起動時コンパイル費用を含まないため、この差をエンドツーエンド性能の改善と解釈しない。時間依存のスケジューラ項目も含み、数%未満の差は測定誤差の可能性がある。ログは`build/jit-lazyir-47-{default,lazyir}.log`。

コード最終検証: 既定モードでCTest 7/7、`XYO_JIT_LAZY_PROCEDURES=1 XYO_JIT_LAZY_IR_OPT=1`でCTest 7/7。最終ビルド後、遅延O3パリティ2回連続で2123/2123。コミットはしていない。
