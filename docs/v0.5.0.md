# xyo-cpp v0.5.0

Scratch 3 parity / runtime correctness update.

- Fixed JIT recursion scheduling to reproduce the bounded stack search in the official Scratch VM, including nested control-block depth and warp behavior.
- Fixed broadcast restarts: a receiver that rebroadcasts itself can finish its current uninterrupted block before the replacement takes over.
- Corrected sprite layer movement, hidden/ghost collision and color sensing, pixel-boundary tests, alpha composition and pen hue wrapping (period 101).
- Corrected rotation-style handling, empty SVG costume bounds, `for each` live bounds and no-microphone loudness.
- Preserved numeric-promotion and scheduler regression checks; included further runtime and JIT optimizations.

## Verification

- CMake CTest: 6 / 6 suites passed on Linux.
- Scratch Parity Test: 2123 / 2123 on hotspot JIT and eager JIT, with SDL offscreen and dummy audio.
- The parity suite is maintained in the separate `scratch-bench/parity` checkout, which is ignored by this repository. To reproduce the fully passing result, apply `tests/patches/scratch-parity-bounce-tolerance.patch` inside that checkout and regenerate `Scratch Parity Test.sb3` with `fractch`.
- The patch replaces a **bit-exact** comparison to `-37.00000000000003` for a bounce direction with `abs(direction() + 37) < 1e-9`. Current V8 computes `-36.999999999999986` for the same official Scratch formula; the change avoids treating engine-specific floating-point last bits as a semantic failure. The implementation is not rounded or special-cased.
- Randomized tests can occasionally fail due to nondeterminism: one hotspot trial got 2122 / 2123 solely from `Operators: Pick Random Rules 2`; a repeat passed 2123 / 2123.

This verification does not claim that all Scratch projects are behaviorally identical, nor that the separately hosted parity suite has been updated upstream.
