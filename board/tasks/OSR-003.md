## Scope

Generic, bounded LLVM OSR source ancestry from the root script through
1..8 actually suspended warp procedure calls to the innermost counted repeat.
Native executes the *remaining loop only*, while every original interpreter
caller keeps GC-rooted argument and exactly one source suffix continuation.
This is deliberately not general NativeCallFrame/SSA/deopt recovery.

## Acceptance criteria

- [x] Static selector records exact source callsite path, with cycle/nonwarp/
      malformed reporters fail closed and 8-caller limit
- [x] Compiled metadata retains complete path + revision, adoption verifies
      each signature/executed stack frame/lexical return ID/source revision
- [x] LLVM completion checks every caller and advances only selected loop
- [x] Direct + hoisted native argument access always uses innermost caller
- [x] Actual promoted depth 4, 6, 8, 9 for 3, 5, 7, 8 callers across three
      native modes; invalid names, nonwarp, >8, disabled DEEP all rejected
- [x] Exact 40,000,058 count across four modes, GC343 with rooted UTF16 args
- [x] Old two/three-frame regression PASS; GUI oracle off/hotspot/eager 2123
- [x] CTest #56 1/1 PASS, isolated coherent v2 build and docs
- [ ] General recursion, nested IF/loop callsites, arbitrary source/effect
      PCs and non-warp yields remain IR-001 / RT-001 integration tasks
