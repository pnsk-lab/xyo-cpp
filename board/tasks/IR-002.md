## Scope

文字列・リスト・GC・描画・音声・broadcast等の副作用を共有の分類とホスト関数ABIで扱う。ロールバック後に観測可能な副作用を再実行しない。

## Acceptance criteria

- [x] Effect opcode分類と副作用境界を文書化する
- [x] GC安全な値/ハンドルABIを定義する（registryとframe sidecar、live統合は別途）
- [x] LLVMとBinaryenが同じホスト側意味論を呼ぶ（実装した6つのValue演算について）
- [x] unsupported effectは必ずfallbackする
