## Result

Integrated into `xyo play` on Linux RTX 3070 via opt-in XYO_DLSS_REAL=1 and XYO_RENDER_SCALE=0.5.
Official NVIDIA NGX DLL/model from local SDK checkout successfully initialized
and evaluated a synthetic Vulkan frame on RTX 3070. No proprietary SDK/model
vendored; 120 real NGX frames and four SDL color/orientation quadrants passed. Real temporal vectors/depth and image-quality validation remain pending. RTX 3070 360-frame mixed mode/resize stress and 240-frame preset switching PASS. After an intermittent regression, 3 consecutive mixed resize/mode/preset 240-frame runs PASS (720/720). For 480x360→1440x1080 Performance mode, K GPU time ~0.994ms, M ~0.927ms, SDK default ~0.915ms. Both standard renderer tests and optional hardware CTest pass.
## Optical Flow update (2026-11-09)
Opt-in flags: XYO_DLSS_OPTICAL_FLOW=1, XYO_DLSS_TEMPORAL=1. NVIDIA RTX 3070 Vulkan dedicated queue family5 -> compute0 with binary GPU semaphores. Genuine 6px current->previous synthetic shift gives -6.000 pixel in hardware SFIXED5 and converted RG16F. Stage GL/Vk optical/NGX integration JIT-enabled xyo play ran >120 frames. CTest optical bridge+optical SDL+baseline SDL 3/3 PASS, 240-frame mode/preset/resize stress PASS. Generic Scratch still lacks true depth, camera jitter and confidence/cuts: temporal opt-in only. Docs docs/pen-dlss-vulkan.md. No SDK vendored.

## Confidence integration (2026-11-09)
GPU 120x90 cost map R8_UINT via NVIDIA NVOFA: high mean >=8 and high cost>=8 fraction >=0.7 triggers temporal reset. Can reset next frame without extra fence or same frame with XYO_DLSS_SCENE_CUT_SYNC=1. In RTX3070 smoke: +6px motion cost mean0.19 -> retain, unrelated scene cut mean13.75 -> reset. SDL optical+NGX end-to-end alternating noise 10/10 cuts flagged after warmup, +6px moving texture 0/10 false flags. OpticalFlow/temporal still opt-in; depth, jitter, confidence calibration remain unimplemented.
## Local motion cost masking
The GLSL shader can now read the concurrent R8_UINT NVOFA cost buffer (GPU-only) while expanding vectors; XYO_DLSS_MOTION_COST_CLIP=1 zeros vectors in high-cost 4x4 cells (byte limit adjustable XYO_DLSS_MOTION_COST_LIMIT). RTX3070 masked 6px motion preserved (-6,0); synthetic cut's incorrect (14.312,4.625) became (0,0) at center. Experimental/off by default; does not prove DLSS quality improvement. True rasterizer jitter cannot be injected through a post-render SDL texture copy.

True subpixel jitter and depth remain unimplemented.\n
## Alpha-safe temporal override (2026-11-09)
Added per-frame forceHistoryReset API and XYO_DLSS_ALPHA_SAFE=1 for visible partial-ghost Scratch sprites, without affecting normal opaque temporal history. RTX3070 real fx_demo.sb3 confirms alpha-safe log + NGX initialization. 90-frame moving 50%-alpha object behind fixed occluder: temporal red trail 0.037, alpha-safe 0.008, temporal off 0.008 (repeat 3x, ~78% lower metric only). Three new GPU tests including automated cross-mode comparison; 14/14 GPU CTests pass. Not generalized to pixel alpha/transparent PNG/SVG, pen, rasterizer jitter, or per-pixel motion. Off by default, no commit.

## Intrinsic costume alpha guard (2026-11-09)
Expanded XYO_DLSS_ALPHA_SAFE=1 to detect stable 3x3 semi-alpha regions in decoded PNG/SVG Skin::px (alpha 8..247, neighbor difference <=24), cached once per costume including disk cache hits. Pixel scan occurs only when both real DLSS and alpha-safe enabled. Partial ghost/skin alpha triggers whole-frame temporal reset only if visible and intersecting stage; fully offstage and hidden sprites skipped. NGX SDK 310.9.16 pInTransparencyMask documented unused/reserved: no region-level temporal resets. New pure CPU test and native NGX GPU-generated .sb3 PNG/SVG eight variants: all PASS (opaque, alpha128, PNG 1px AA border, SVG opaque circle, offstage PNG, hidden SVG). Full targeted CTest 18/18 PASS including xyo-tests+renderer+CPU classifier+15 GPU. Undetected: very thin partial alpha, pen, post-processing effects. No commits.
