## Scope

Bounded, opt-in interpreter-restoring deoptimization at an actual native Fiber scheduler yield after the completed body of a flat counted warp repeat. Fail closed if source changes without a complete safe checkpoint. IR/RT owned CallFrame/deopt code unchanged.
