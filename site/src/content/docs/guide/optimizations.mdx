## ステータスの読み方

- **既定有効**: 通常の対象経路で適用される最適化。適用できない入力では従来の処理へ戻ります。
- **条件付き**: JITモード、証明できる値域、読み取り専用ループなど、特定の条件下だけで適用されます。
- **試験的・明示有効**: 環境変数などで明示的に有効化する機能。計測・互換性検証のための段階です。

環境変数は、特記がなければ **JITコード生成前**に指定してください。無効化スイッチはA/B比較用であり、一般に最速設定とは限りません。

## LLVM JIT・数値演算

| 最適化 | 適用範囲・方法 | 状態 / 切替 |
| --- | --- | --- |
| [型フィードバック](/xyo-cpp/research/jit-type-feedback/) | HotSpotが観測した数値型を利用。実行時にタグを検査して安全な数値経路へ進む | 条件付き / `XYO_JIT_TYPE_PROFILE` |
| [数値SSA・整数性伝播](/xyo-cpp/research/jit-v1-numeric-optimizer-2026-11-04/) | 有限時の整数性をLLVM SSA値で追跡し、不要な変換や検査を省く | 既定有効、演算により個別スイッチ |
| [整数剰余の符号付き変換](/xyo-cpp/research/jit-ssa-arithmetic-2026-11-04/) | 値域をガードできる剰余計算を32bit整数演算へ変換 | 既定有効 / `XYO_JIT_MOD_SIGNED_I32=0` |
| [丸め演算のインライン化](/xyo-cpp/research/jit-v1-numeric-optimizer-2026-11-04/) | `roundeven` と0.5境界補正によりScratchの丸め規則を維持 | 既定有効 / `XYO_JIT_ROUND_INLINE=0` |
| [ループ内変数のレジスタ昇格](/xyo-cpp/research/jit-ssa-arithmetic-2026-11-04/) | ホットループで変数・数値シャドウを保持。中断時には必要な値を同期 | 条件付き |
| [Epoch-Guarded Loop](/xyo-cpp/research/epoch-guarded-loop-2026-11-05/) | 読み取り専用変数の無用な書き戻しを削除。GC世代と値を照合する数値シャドウ再利用も試験 | 前半は既定有効 / 追加ガードは `XYO_JIT_EPOCH_GUARD=1` |
| [ループ不変の三角関数](/xyo-cpp/research/jit-loop-invariant-trig-2026-11-05/) | 読み取り専用の角度に対するsin/cosをループ前に計算し、スケジューラ復帰時に更新 | **試験的** / `XYO_JIT_TRIG_HOIST=1` |
| [JITの比較高速経路](/xyo-cpp/research/jit-symmetric-equality-2026-11-03/) | 数値・文字列などの種類と等値性に応じて比較を特殊化。例外型は通常経路 | 条件付き |
| [ASCIIリテラル比較](/xyo-cpp/research/scratchbench-brainfuck-ast-2026-11-05/) | 記号を含む短いASCIIリテラルとの等値比較を直接判定 | 条件付き |
| [数字集合の包含判定](/xyo-cpp/research/scratchbench-brainfuck-ast-2026-11-05/) | `0123456789` に1文字が含まれるかを型・長さガード付きで判定 | 既定有効 / `XYO_JIT_DIGIT_CONTAINS=0` |

代表的な単独実験です。測定環境・ベースラインが異なるため、**複数行の改善率を足したり掛けたりして総合性能と解釈しないでください**。

## 最適化の確認と比較

```bash
# 通常のHotSpot JIT
build/xyo run project.sb3 --jit hotspot

# 例: 文字列のTransient最適化を無効化して差分を測定
XYO_JIT_TRANSIENT_STRINGS=0 build/xyo run project.sb3 --jit hotspot

# 例: 試験中の数値専用リスト最適化を有効化
XYO_JIT_NUMERIC_LIST=1 build/xyo run project.sb3 --jit eager

# 対応する回帰テスト
ctest --test-dir build --output-on-failure
```

最適化の評価では、実行時間だけでなく、初回コンパイル時間・ピークRSS・出力チェックサム・タイマーおよびWarpの意味論を分けて確認してください。詳細は[ベンチマークとテスト](/xyo-cpp/development/testing/)および[Scratch Bench](/xyo-cpp/reference/scratch-bench/)を参照してください。
