<section class="xyo-section">
  <div class="xyo-section-head">
    <span class="xyo-kicker">Architecture &amp; Passes</span>
    <h2>Scratch の意味論を保ったまま、コンパイラ技術を総動員</h2>
    <p>動的型・暗黙キャスト・フレーム同期・Warp 時間制限といった Scratch 固有の仕様を厳密に守りつつ、計算・スケジュール・メモリを多層で最適化します。</p>
  </div>

  <div class="xyo-bento">
    <div class="xyo-card xyo-span-3">
      <div class="xyo-card-head">
        <span class="xyo-card-title">MLIR 前段 &amp; LLVM ORC JIT</span>
        <span class="xyo-pill">xyo dialect</span>
      </div>
      <p>ブロック木を独自の <code>xyo</code> MLIR 風 IR へ落とし込み、値域・整数性・数値ビット証明を伝播させたうえで LLVM ORC JIT がネイティブ機械語を生成します。インタプリタ開始の HotSpot と即時コンパイルの Eager を選択可能です。</p>
      <div class="xyo-card-tags">
        <code>--jit=hotspot</code><code>--jit=eager</code><code>XYO_MLIR=1</code>
      </div>
    </div>

    <div class="xyo-card xyo-span-3">
      <div class="xyo-card-head">
        <span class="xyo-card-title">Mega スケジューラ &amp; スタックレス継続</span>
        <span class="xyo-pill">Fiberless</span>
      </div>
      <p>手続きグラフを 1 関数へ融合し、yield を含む非 warp スクリプトや再帰手続きも LLVM コルーチンへ変換。OS ファイバの切り替えコストを抑えながら、依存解析に基づく安全なマルチスレッド並列実行を行います。</p>
      <div class="xyo-card-tags">
        <code>--mega</code><code>llvm.coro</code><code>Worker Pool</code>
      </div>
    </div>

    <div class="xyo-card xyo-span-2">
      <div class="xyo-card-head">
        <span class="xyo-card-title">matpow / par-for / DP</span>
        <span class="xyo-pill">Auto Transform</span>
      </div>
      <p>漸化式ループの O(log N) 行列累乗化（f64 厳密範囲証明付き）、純粋再帰のトップダウン DP 化、独立 append ループの並列化を自動で適用します。</p>
    </div>

    <div class="xyo-card xyo-span-2">
      <div class="xyo-card-head">
        <span class="xyo-card-title">AOT 単体コンパイル</span>
        <span class="xyo-pill">Zero Warmup</span>
      </div>
      <p>全スクリプトを O2 でオブジェクト化し、プロジェクトデータと同梱した単体バイナリを生成。非対応箇所は安全にフォールバックします。</p>
    </div>

    <div class="xyo-card xyo-span-2">
      <div class="xyo-card-head">
        <span class="xyo-card-title">解析・縮小・書き換えツール</span>
        <span class="xyo-pill">CLI Suite</span>
      </div>
      <p>実行せずに構造と計算量を解析する <code>analyze</code>、可逆圧縮の <code>minify</code>、安全な warp 化を行う <code>rewrite</code> を内蔵しています。</p>
    </div>
  </div>
</section>

  (() => {
    const root = document.querySelector('[data-xyo-terminal]');
    if (!root) return;
    const tabs = root.querySelectorAll('[data-tab]');
    const panes = root.querySelectorAll('[data-pane]');
    const copyBtn = root.querySelector('[data-copy-btn]');

    const activate = (id) => {
      tabs.forEach((t) => t.classList.toggle('is-active', t.dataset.tab === id));
      panes.forEach((p) => p.classList.toggle('is-active', p.dataset.pane === id));
    };

    tabs.forEach((tab) => {
      tab.addEventListener('click', () => activate(tab.dataset.tab));
    });

    if (copyBtn) {
      copyBtn.addEventListener('click', async () => {
        const active = root.querySelector('.xyo-term-pane.is-active');
        const cmd = active?.getAttribute('data-cmd') || '';
        if (!cmd) return;
        try {
          await navigator.clipboard.writeText(cmd);
          copyBtn.textContent = 'Copied!';
          setTimeout(() => { copyBtn.textContent = 'Copy'; }, 1400);
        } catch {
          copyBtn.textContent = 'Copy';
        }
      });
    }
  })();
`}</script>
